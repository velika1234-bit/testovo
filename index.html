⚠️

Достъпът е отказан

Базата данни във Firebase е "заключена".

Как да поправите това (стъпка по стъпка):

  1. Отворете Firebase Console и влезте във вашия проект.
  2. Отидете на Build -> Firestore Database.
  3. Кликнете на таба Rules (горе в средата).
  4. Изтрийте всичко там и поставете този код:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Основен път на приложението
    match /artifacts/videoquiz-ultimate-live {
      
      // 1. ПУБЛИЧНИ ДАННИ (Сесии на живо)
      match /public/data/{document=**} {
        allow read, write: if true;
      }

      // 2. ДАННИ НА УЧИТЕЛЯ (Лична папка)
      // Учителят има пълен контрол над всичко в своята папка
      match /users/{userId}/{document=**} {
        allow read, write: if request.auth != null && request.auth.uid == userId;
      }
      
      // 3. ИЗКЛЮЧЕНИЕ ЗА РЕЗУЛТАТИ (Индивидуален режим)
      // Позволяваме на учениците (всеки логнат, вкл. анонимно) да ЗАПИСВА резултат
      match /users/{teacherId}/solo_results/{resultId} {
         allow create: if request.auth != null;
      }
    }
  }
}

След това натиснете "Publish" и презаредете тази страница.
